# Experiment 4: Find the Last Connected USB Device Using USBDeview

## Aim
To identify the last connected USB device using USBDeview.

## Tool Used
- USBDeview

## Procedure
1. Download and open USBDeview on a Windows system.
2. Run the application and view the list of USB devices.
3. Examine the available device information.
4. Check the connection and disconnection details, if available.
5. Identify the most recently connected USB device based on the displayed information.
